Tag Scanner Tool

Instructions

The original Pico (C/S) identifies a recipe by the NFC/RFID tag glued into each PicoPak. Whenever a Pico scans one -- starting a brew, or hitting an error mid-scan -- it sends the tag's ID to this server, which is captured below in real time. Use this page to figure out what a tag actually is: scan a PicoPak on your Pico and watch it show up in the log, or paste a tag ID directly if you already have one (e.g. from a phone NFC reader).
